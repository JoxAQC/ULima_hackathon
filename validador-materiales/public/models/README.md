# Modelos locales (TFLite)

Coloca tus modelos y etiquetas aquí, por misión:

- `public/models/horno_solar/model.tflite`
- `public/models/horno_solar/labels.json`
- `public/models/luz_botella/model.tflite`
- `public/models/luz_botella/labels.json`

Opcional: crea tu propio `config.json` si cambias rutas, tipo de modelo (image_classification u object_detection), o thresholds.
