# **App Name**: HIRI Prototype

## Core Features:

- User Segmentation: Determine user segment (Adult/Youth) based on age input during profile creation.
- Differentiated Home Screens: Display a home screen tailored to the user segment: financial metrics for adults, virtual village and community ranking for youth.
- Offline Mini-Missions: Provide offline access to mini-missions with step-by-step tutorials.
- Audio Assistance: Provide audio descriptions for each step in a mini-mission.
- Progress Tracking: Track user progress through modules and missions.
- Impact Measurement: Measure and display the impact of completed missions, such as financial savings (for adults) or social status (for youth).
- Gamified Rewards: Award 'EXP' (experience points) or 'HIRI Credits' upon mission completion.

## Style Guidelines:

- Adult: #35641D for navigation bar background and main titles to provide solidity and contrast.
- Success: #5A9D1C / #82B22A for success indication and main action buttons like 'Complete Mission'.
- Youth: #A5D64C for virtual village background and progress bars, creating an attractive, energetic, and fun feel.
- General: #A9AD7C as a soft neutral background for screens and offline information containers to reduce visual fatigue.
- Neutral: #F9F9F9 (very soft white) for content card backgrounds and secondary text to maximize legibility.
- Alert: #FF6B6B (Red or Orange) for alerts, reminders, and error notifications to contrast success and draw user attention.
- Use 'Poppins' (sans-serif) for a clear and legible font that scales well for micro-lessons.
- Use high-contrast, easily understandable icons suitable for users with limited digital experience.
- Implement a fixed bottom navigation bar with 4-5 main tabs: Home/My Village, Missions/Learn, My Impact, Profile/Settings.
- Subtle animations and transitions to guide users through the app and provide feedback.
